نظام ذكي لإدارة الأدوية والالتزام بالعلاج

Smart Medication Adherence & Safety System

وصف المشروع

نظام ويب وتطبيق موبايل ذكي يربط الوصفة الطبية مباشرة بالتطبيق، ويُمكّن الطبيب من متابعة العلاج وترتيب الجرعات، بينما يستقبل المريض تنبيهات ذكية مع تحليل للتداخلات الدوائية ومتابعة الالتزام.

آلية عمل النظام

الطبيب يكتب الوصفة → تصرف في الصيدلية → تصل البيانات تلقائيًا للنظام → تظهر الأدوية في تطبيق المريض → يبدأ التذكير والمتابعة → الطبيب يراجع التقارير.

المشكلة التي يحلها المشروع

  • نسيان الجرعات
  • تعارض الأدوية
  • أخطاء إدخال البيانات
  • ضعف متابعة العلاج
  • صعوبة إدارة الأدوية لكبار السن

المميزات الأساسية

الميزة الوصف الفائدة
ربط الوصفة تلقائيًا استقبال البيانات من الصيدلية عبر API منع الأخطاء اليدوية
تنبيهات ذكية إشعارات بموعد الجرعات زيادة الالتزام
كشف التداخلات تحليل جميع الأدوية معًا منع المخاطر
متابعة الطبيب لوحة تحكم للطبيب لمراجعة الحالة إشراف علاجي حقيقي
تسجيل الأعراض المريض يسجل الأعراض الجانبية تنبيه مبكر للمضاعفات

التقنيات المستخدمة

  • Frontend: React
  • Backend: Node.js
  • Database: MySQL
  • AI Analysis
  • OCR لاستخراج الوصفات
  • Firebase Notifications

الفائدة العملية

  • تقليل الأخطاء الطبية
  • زيادة الالتزام بالعلاج
  • متابعة مباشرة من الطبيب
  • نظام قابل للتطبيق في المستشفيات
